libsodium-php (PECL package)
=============================

**This PECL package is archived.**

The libsodium extension has been bundled with PHP since PHP 7.2, which means that anyone running a supported version of PHP already has it available — no PECL installation is required.

As of today, the oldest version of PHP that is still supported is PHP 8.2, and all such versions include the libsodium extension out of the box.

If you are using a modern, supported version of PHP, simply enable the extension in your `php.ini`:

```ini
extension=libsodium
```

No further action is needed.
